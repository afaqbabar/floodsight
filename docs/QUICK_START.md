# 🚀 FloodSight Quick Start

Everything is ready! Here's what to do next.

---

## ⚡ 3-Minute Setup

```bash
# 1. Install Node.js (if needed)
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 2. Install dependencies
cd /home/lenovo/scrimba/floodsight/floodsight
npm install

# 3. Start dev server
npm run dev
# → Open http://localhost:8000
```

---

## ✅ Run Checks

```bash
npm run format      # Format code
npm run lint        # Check JavaScript
npm run lint:html   # Check HTML
npm test            # Run all tests
npm run lighthouse  # Performance audit (needs dev server running)
```
