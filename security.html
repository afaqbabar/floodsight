Security

How FloodSight protects data, systems, and users.

1. Hosting & infrastructure

  • FloodSight is hosted on Vercel (EU and US data centers).
  • Vercel provides HTTPS, access controls, and distributed edge hosting.
  • We use GitHub for version control with 2FA enforced.

2. Data protection

  • All traffic uses HTTPS (TLS 1.2+).
  • No personal data is stored outside of Formspree form submissions.
  • Form data is only used for pilot participation and deleted upon request.

3. Responsible disclosure

If you discover a vulnerability, please contact security@floodsight.com. We appreciate responsible reporting and will respond promptly.

4. Future roadmap

  • Planned ISO 27001-aligned internal policies as we move toward production.
  • EU-hosted storage for Copernicus/ECMWF derived data (GDPR-compliant).

5. Contact

Email: security@floodsight.com
